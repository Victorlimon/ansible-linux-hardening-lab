# CIS Benchmark 6.3: Configure Integrity Checking (AIDE)

## 📋 Resumen de Controles

| Control | Nivel | Estado | Descripción |
|---------|-------|--------|-------------|
| **6.3.1** | Level 1 | ✅ Automatizado | Ensure AIDE is installed |
| **6.3.2** | Level 1 | ✅ Automatizado | Ensure filesystem integrity is regularly checked |
| **6.3.3** | Level 2 | ✅ Automatizado | Ensure cryptographic mechanisms protect audit tools |

## 🔧 Configuración por Variable

### 6.3.1 - AIDE Installation
```yaml
section6_logging:
  '6_3_1_aide_installed':
    enabled: true
    packages:
      - aide
      - aide-common
  
  '6_3_1_aide_init':
    enabled: true
    db_path: "/var/lib/aide/aide.db"
    db_new_path: "/var/lib/aide/aide.db.new"
```

### 6.3.2 - AIDE Timer Configuration
```yaml
section6_logging:
  '6_3_2_aide_timer':
    enabled: true
    timer_name: "dailyaidecheck.timer"
    service_name: "dailyaidecheck.service"
    timer_on_calendar: "*-*-* 05:00:00"  # 5 AM daily
  
  '6_3_2_aide_wrapper':
    enabled: true
    wrapper_path: "/usr/bin/aide.wrapper"
    use_wrapper: true  # Ubuntu recommendation
```

### 6.3.3 - Audit Tools Integrity (Level 2)
```yaml
section6_logging:
  '6_3_3_aide_audit_tools_integrity':
    enabled: true  # Set to false for Level 1 only
    aide_conf: "/etc/aide/aide.conf"
    audit_tool_attrs: "p+i+n+u+g+s+b+acl+xattrs+sha512"
    audit_tools:
      - "/usr/sbin/auditctl"
      - "/usr/sbin/auditd"
      - "/usr/sbin/ausearch"
      - "/usr/sbin/aureport"
      - "/usr/sbin/autrace"
      - "/usr/sbin/augenrules"
  
  '6_3_3_aide_conf_permissions':
    enabled: true
    mode: '0640'
    owner: "root"
    group: "root"
  
  '6_3_3_aide_config_validation':
    enabled: true
    validate_cmd: "aide --config-check"
```

## ⚠️ Consideraciones Importantes

### 🔁 Primera Ejecución - Inicialización de Base de Datos
```bash
# La primera ejecución inicializará la base de datos AIDE
# Esto puede tomar varios minutos dependiendo del filesystem
ansible-playbook ... --tags "cis_6_3_1" -vvv

# Verificar que la base de datos se creó correctamente
ssh ubuntu-server "aide --check"
```

### 📦 Espacio en Disco Requerido
- AIDE requiere espacio para almacenar la base de datos (~50-200 MB típicamente)
- El proceso `aide --update` requiere espacio temporal adicional
- Asegurar al menos 500 MB libres en `/var/lib/aide/`

### ⏱️ Tiempo de Ejecución
| Tarea | Tiempo Estimado |
|-------|----------------|
| Instalación de paquetes | ~30 segundos |
| Inicialización de DB (primera vez) | 5-15 minutos |
| Actualización de DB (subsiguientes) | 2-5 minutos |
| Verificación de integridad | 3-10 minutos |

### 🔄 Actualización de Base de Datos
Después de cambios significativos en el sistema:
```bash
# Actualizar base de datos AIDE manualmente
ssh ubuntu-server "sudo aide --update"
ssh ubuntu-server "sudo mv /var/lib/aide/aide.db.new /var/lib/aide/aide.db"
```

## 🧪 Validación Post-Implementación

```bash
# 1. Verificar que AIDE está instalado
ssh ubuntu-server "dpkg-query -s aide | grep Status"

# 2. Verificar que la base de datos existe
ssh ubuntu-server "ls -la /var/lib/aide/aide.db"

# 3. Verificar que el timer está activo
ssh ubuntu-server "systemctl is-active dailyaidecheck.timer"

# 4. Ejecutar verificación manual de integridad
ssh ubuntu-server "sudo aide --check"

# 5. Validar configuración de herramientas de auditoría
ssh ubuntu-server "aide --config /etc/aide/aide.conf -p f:/usr/sbin/auditctl"
```

## 🔍 Troubleshooting

### ❌ Error: "AIDE database not found"
```bash
# Solución: Forzar re-inicialización
ansible-playbook ... --tags "cis_6_3_1" -e "force_aide_init=true"
```

### ❌ Error: "Timer failed to start"
```bash
# Verificar estado del timer
ssh ubuntu-server "systemctl status dailyaidecheck.timer"
ssh ubuntu-server "journalctl -u dailyaidecheck.timer -n 50"

# Recargar systemd y reintentar
ssh ubuntu-server "sudo systemctl daemon-reload"
ansible-playbook ... --tags "cis_6_3_2"
```

### ❌ Error: "AIDE config validation failed"
```bash
# Revisar sintaxis del archivo de configuración
ssh ubuntu-server "sudo aide --config-check"
ssh ubuntu-server "sudo tail -20 /var/log/aide/aide.log"

# Corregir manualmente si es necesario, luego revalidar
ansible-playbook ... --tags "cis_6_3_3_4"
```
