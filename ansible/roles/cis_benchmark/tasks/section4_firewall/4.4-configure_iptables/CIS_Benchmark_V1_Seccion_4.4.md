IPtables is an application that allows a system administrator to configure the IPv4 and  IPv6 tables, chains and rules provided by the Linux kernel firewall. If IPv6 is in use in your  environment, similar settings should be applied to the IP6tables as well. It is recommended to transition towards either   nftables   or   ufw   as the  default firewall management tool.
